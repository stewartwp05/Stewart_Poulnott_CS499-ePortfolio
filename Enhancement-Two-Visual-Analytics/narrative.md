For this enhancement I added a chart to show weight over time because the only “visualization” being a bunch of numbers in rows wasn't the best way to captivate the information. You can't really tell if you're making progress or what the trend looks like when it's just data in a table. I added the MPAndroidChart library to my project and put a LineChart view in the layout between the goal section and the weight history. Then I had to write code in DashboardActivity.kt to actually get the weights from the database and get them into a format the chart could work with. The problem was my database returns everything newest first which works fine for the table but the chart needed oldest first so it goes left to right like a timeline. I reversed the list and looped through making Entry objects - x is just 0, 1, 2 for each position and y is the weight value. I also made another list holding the dates as I went. After that I wrote a ValueFormatter so when the chart wants to label the bottom axis it can look up what date goes with each position instead of just showing numbers.
The annoying part was flipping everything around without losing which date matched which weight. I basically had two lists running side by side - chart entries in one and dates in the other - so position 3 in one list lines up with position 3 in the other. When I tested it with actual weight data the line showed up connecting the dots, dates appeared along the bottom, and pinch to zoom worked. It was good practice for taking data that's set up one way and reshaping it for something completely different.
