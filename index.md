## About Me

I am a Computer Science student at Southern New Hampshire University specializing in mobile application development. This ePortfolio showcases my capstone project enhancements to the WeightTracker Android application.

## Professional Self-Assessment

Completing my Bachelors in Computer Science while working full-time wasn't easy, but it taught me how to balance everything and stick to deadlines even when things got hectic. The capstone project made me pull together everything from different classes into something concrete I can show employers instead of just explaining what I learned. Building this ePortfolio around the WeightTracker Android app forced me to think about presenting my skills in a clear way. The program covered collaboration through CS-250 Agile methodology and group discussions, which helped with understanding sprint planning and stakeholder communication. Making the code review video and participating in discussion boards helped me get better at explaining technical stuff to people who don't have a programming background. Data structures and algorithms started making sense when I stopped trying to memorize everything and figured out it's really about choosing the right tool for the situation. The chart enhancement is a good example - I had to convert weight data from one format to another while keeping track of which dates went with which numbers. Software engineering really came together when I did the password hashing work. I had to take code that was already working and make it better, plus write the migration stuff to handle users who already had accounts. CS-405 taught me to think about security from the beginning instead of trying to add it in after you've already built everything.
All three artifacts come from the WeightTracker app but each one shows different abilities. I used one project instead of three separate ones because it demonstrates I can take existing code and enhance it in multiple ways. Enhancement One added SHA-256 password hashing which shows I can spot security problems and fix them properly. Enhancement Two put in chart visualization which demonstrates working with data transformations and user interface design. Enhancement Three optimizes database performance with indexes, foreign keys, and transactions. Together they prove I can handle security, algorithms, databases, and user experience while working with existing code, which is what happens in real development since you're usually improving systems that already have users depending on them.
